## About The Project

This repository does not hold a Surge proxy configuration; it holds a record of maintaining one. `operation-log.md` is a dated changelog of edits made to a Surge profile that lives outside this repository, on the maintainer's own Mac -- entries such as switching an OpenAI rule set over to Surge's built-in Tailscale exit node, or syncing a proxy subscription's server list. `openai-tailscale-research-2026-09-07.md` is a separately sourced research note comparing OpenAI's published network guidance against the rule set in use, with citations for every claim. `PROJECT_STATUS.md`, generated by the maintainer's own workspace-management tooling rather than by this documentation pass, independently reaches the same conclusion: no manifest, no source code of any language, and no run step exist here. `.firecrawl/` holds a snapshot of the third-party rule fragments and vendor documentation those log entries cite.

See the [open issues](https://github.com/anyingiit/config_surge/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- Git, to clone the repository.
- Optionally, Python 3.9 or newer with `pip install pre-commit`, to run the hook set in `.pre-commit-config.yaml` locally. Nothing else is required: there is no compiler, interpreter, or package manifest anywhere in this repository.

### Installation

```sh
git clone https://github.com/anyingiit/config_surge.git
cd config_surge
pre-commit install  # optional: runs the hooks below before each commit
```

There is no build step: cloning gives you the complete contents of the repository as it stands today.

## Usage

There is no program to run. Read `operation-log.md` for the dated history of changes applied to the Surge profile that lives outside this repository, and `openai-tailscale-research-2026-09-07.md` for the sourced research behind the 2026-09-07 OpenAI routing change it describes. `.firecrawl/` holds the raw rule fragments and documentation snapshot those entries cite, for example:

```
.firecrawl/anthropic-added-rules.txt
```
